# Read와 Processed를 별도 상태로 분리

Article의 "사용자가 읽었다"(Read)와 "Scrape가 처리를 끝냈다"(Processed)는 원래 한 상태였다. 하나로 두면 두 주체가 같은 값을 두고 다툰다 — Scrape가 실패 후 재시도하면서 사용자가 읽은 표시를 되돌리거나, 반대로 사용자가 읽음 처리한 Article을 Scrape가 미처리로 보고 다시 집어간다. 바꾸는 주체도 이유도 다른 상태라 판단해 둘로 나눴고, 기존 데이터는 Read인 Article을 Processed로 백필했다.

두 값이 대체로 같이 움직여서 중복처럼 보이지만, 합치면 위 문제가 그대로 돌아온다.
